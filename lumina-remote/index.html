Lumina Remote

Download the free host

Install this on the computer you want to control, then connect from the Lumina Remote app on your iPhone or iPad.

The host runs quietly in the background — the menu bar on Mac, the system tray on Windows — and lets the Lumina Remote app stream your screen and control it. It's free, and your screen stream stays encrypted between your own devices.

◉ macOS

macOS 13 Ventura or later · Apple Silicon & Intel · notarized
Download for Mac
Open the app, grant Screen Recording & Accessibility when asked, then click Start.

◉ Windows

Windows 10 or 11 (64-bit)
Download for Windows (.exe)
Unzip, run LuminaRemoteHost.exe. If SmartScreen appears, choose “More info → Run anyway.”

How to connect

  1. Install and open the host on your Mac or Windows PC — it starts advertising on your network.
  2. On your iPhone/iPad, open Lumina Remote and tap Add device (scan QR).
  3. Scan the pairing code the host shows (Mac: menu bar → Pair a device · Windows: tray → Show pairing code).
  4. Tap the computer to connect. You'll see its screen live and can control it with touch and keyboard.

Away from home?

  1. Install Tailscale on the iPhone and the computer, signed in to the same account (free for personal use).
  2. In Lumina Remote, use Connect by IP with the computer's Tailscale address (the 100.x.y.z one).
